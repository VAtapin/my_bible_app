# Bible Desktop Native Mobile

Полностью нативные клиенты Bible Desktop. Здесь нет WebView и не встраивается
PWA.

## Архитектура

- `androidApp` — Android UI на Jetpack Compose;
- `iosApp` — iOS UI на SwiftUI;
- `sharedLogic` — модели, Ktor API-клиент и Swift-friendly loaders на Kotlin
  Multiplatform;
- production API — `https://bible-desktop.com/api`.

Идентификатор обеих платформ: `com.bibledesktop.myapp`. Текущая версия:
`0.1.0` (build 1).

Android debug имеет отдельный идентификатор `com.bibledesktop.myapp.debug`
и название «Bible Desktop · Тест». Он не заменяет release-приложение и не
использует его сохранённые данные. Автоматическая миграция данных старой
Capacitor-версии пока не реализована.

## Реализованные сценарии

- интерфейс RU/DE/UK/EN, язык выбирается сразу на старте;
- стартовый hero с оригинальным храмом: вся ширина телефона/портретного
  планшета, левая половина широкого альбомного окна;
- месяц BibleDesktop и сводка дня до настройки и на «Сегодня»;
- быстрый запуск одним нажатием: все работающие нативные разделы
  (Библия/молитвы/календарь), перевод языка интерфейса плюс CU/CU-civil;
- ручная настройка сохранена;
- выбор разделов и нескольких переводов независимо от языка интерфейса;
- экран «Сегодня» с составом приложения;
- Библия: перевод → книга → глава → чтение, размер текста, закладки, share;
- Android: каталог полных закладок, открытие сохранённого места и автоматическое
  продолжение последней главы;
- Android: заметка к стиху, создание/редактирование, список в «Ещё», открытие
  главы, подтверждаемое удаление. Локальный version1 JSON в существующих
  SharedPreferences профиля, фоновое чтение/commit записи. Отмена не сохраняет
  черновик, повреждённые данные не перезаписываются; ключи закладок совместимы;
- молитвы: независимый выбор языка текста/редакции → чтение, размер текста, share;
- Ponomar для CU и Monomakh для CU-civil встроены вместе с OFL; HTML молитв
  преобразуется в текст без WebView, источник не выводится;
- церковный календарь: месяц и неделя (включая переход между месяцами), старый
  стиль, пост, памяти и чтения. Иконы в порядке BibleDesktop, только превью в
  списках; большая галерея со свайпом и стрелками. Пять знаков Типикона и восемь
  пищевых/поминальных отметок встроены, сетка использует назначенные API знаки;
- тексты дня для Шестого часа: независимый выбор редакции, CU-civil по умолчанию,
  раскрываемые тексты и масштаб. Предупреждения о неполном уставном плане API
  сохраняются; это справочная панель, не полный текст последования Часа.
- Android-офлайн: открытые главы, каталоги, молитвы, месяцы, дни и тексты служб
  сохраняются атомарно в noBackupFilesDir, а не в очищаемом системном кэше.
  Локальные данные читаются сразу; старше суток обновляются в фоне при сети
  и показываются обновлёнными при следующем открытии. Неизвестная схема не
  перезаписывается, запись ограничена 5 MiB на JSON и 256 MiB суммарно;
- «Ещё → Без сети»: WorkManager-пакет текущего и следующих 29 дней, месяцы,
  CU-civil тексты дня и первое API-превью каждой разрешённой к хранению иконы
  (до 384 KiB / 1024 px). Большие оригиналы не входят в пакет. Есть Wi-Fi-only,
  счётчик дней, ожидание/готово/ошибка, отмена и продолжение по атомарным
  checkpoints. Повторная новая загрузка обновляет данные пакета. Запросы
  календаря ограничены до 24/мин с запасом к серверному лимиту 30/мин;
  429/5xx и Retry-After учитываются без изменения серверных ограничений.

Android-сценарии проверены на эмуляторе API 37 с production API. SwiftUI-код
требует первой сборки и проверки на macOS.

## Android

Требуются JDK 25, Android SDK 37 и Android Studio 2026.1.4 или новее.

Из каталога `mobile`:

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
$env:ANDROID_HOME='C:\Users\atapi\AppData\Local\Android\Sdk'
.\gradlew.bat :sharedLogic:testAndroidHostTest :androidApp:assembleDebug
```

Debug APK:
`androidApp/build/outputs/apk/debug/androidApp-debug.apk`.

### Проверка базовых сценариев

На запущенном эмуляторе (не физическом телефоне), из каталога `mobile`:

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
$env:ANDROID_HOME='C:\Users\atapi\AppData\Local\Android\Sdk'
$env:ANDROID_SERIAL='emulator-5556'
.\gradlew.bat :sharedLogic:testAndroidHostTest :androidApp:connectedDebugAndroidTest :androidApp:assembleDebug
```

Укажите serial своего эмулятора. На 08.10.2026 прошли десять тестов общего
клиента и двадцать семь instrumentation-тестов на BibleDesktop_API_37: первый запуск,
ручная настройка/системный возврат, одношаговый старт/переходы основных экранов,
четыре языка, пересоздание activity, настоящий поворот, три размера окна,
чтение реальных ответов BibleDesktop для переводов, книг, главы, молитвы и дня.
Проверка API требует сети; фиксированная дата — 08.10.2026. Тесты не создают
серверные профили, допускают только debug-пакет и восстанавливают изменённые
настройки после каждого теста. Физический телефон не проверен.

Также пройден `:androidApp:lintDebug`: 0 ошибок, 42 предупреждения, 2 подсказки.
Три снимка UI проверены; ресурсные каталоги DE/UK/EN содержат все ключи RU.
Заметки проверены через настоящее Android-хранилище, Save/Cancel/Delete
диалоги и весь сценарий от стиха до личного списка. Проверка физической
перезагрузки телефона пока не проводилась.
Офлайн: реальный 30-дневный пакет 08.10–06.11.2026 и обе месячные сетки,
повторное открытие store/repository с недоступным источником, сохранённые
главы/молитвы/службы/превью, продолжение checkpoints, отмена coroutine и
реальная кнопка отмены WorkManager проверены. Общие HTTP-тесты покрывают
429/503, Retry-After и запрет повторять 403. Все запросы production — только GET.
Полный набор Android — 26 тестов, затем отдельно добавленный UI-тест отмены;
повторно весь сетевой пакет ради commit не запускался.

Офлайн-пакет требует несколько минут: день считается готовым только после
сохранения текста, службы и всех доступных для локального хранения превью.
Если права на локальное хранение иконы не разрешены API, её изображение в
пакет не включается. В офлайн-галерее доступно сохранённое первое превью,
остальные варианты требуют сети. Данные переживают обычное закрытие приложения;
удаление приложения удаляет и его локальные данные.

Это ещё не полная паритетная версия PWA. Нативные study/Азбука и напоминания
пока не работают и не входят в быстрый пакет. Английский интерфейс явно
помечает русский календарный корпус. Часы/случайный стих главной, массовая
загрузка книг/молитвенных сборников, управление размером пакетов,
синхронизация и миграция прежних данных требуют отдельных реализаций.
Физический авиарежим/перезагрузка телефона и восстановление фоновой задачи
после перезагрузки ещё не проверены; механизм WorkManager подключён.

## iOS

Открыть `iosApp/iosApp.xcodeproj` на macOS в Xcode. В локальной копии указать
Apple Developer Team для target `iosApp`; сертификаты и signing secrets в Git не
добавлять. Xcode вызывает `:sharedLogic:embedAndSignAppleFrameworkForXcode` перед
сборкой. Минимальная версия iOS — 16.0.

## Подтверждённое ограничение API

На 18 сентября 2026 года `/api/prayers?language=de` возвращает русские записи.
Клиенты фильтруют ответ по фактическому `language_code`, поэтому русские молитвы
не выдаются за немецкие. Немецкий корпус должен быть импортирован на стороне
основного Bible Desktop API.
