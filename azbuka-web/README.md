# «Азбука с цифирью» — Web App

Самостоятельный браузерный клиент тренажёра церковнославянской азбуки. Установка не требуется; после первого успешного открытия приложение работает offline как PWA.

Те же экраны, учебная логика, часы и хранилище подключены как плагин внутри
Biblia App по `/education/azbuka`. Это один источник кода, не копия приложения
и не переход на внешний сайт. Прогресс остаётся локальным для каждого origin;
автоматическая синхронизация между доменами пока не реализована.

## Что реализовано

- адаптивный app-like UI для телефона и компьютера;
- церковнославянский интерфейс по умолчанию с переключением на русский или
  немецкий в настройках;
- 37 учебных карточек букв и знаков;
- отдельный раздел церковнославянской цифири от 1 до 999 с пошаговым алгоритмом,
  правилами и таблицами разрядов;
- буквенные упражнения «знак → имя» и «имя → знак», не смешанные с цифирью;
- живые часы, минуты и секунды церковнославянской буквенной цифирью;
- локальные прогресс, точность, серия занятий и настройки в IndexedDB;
- прямые URL экранов и offline service worker;
- локально поставляемый шрифт Ponomar под SIL OFL 1.1.
- церковнославянский словарь: поиск по исходному/гражданскому слову и русскому
  значению, просмотр исходных алфавитных разделов, полные статьи, избранное
  и история на устройстве. Один экран работает отдельно и внутри Bible App.

Подключение API, прямые ссылки и граница ответственности WordPress shortcodes:
[AZBUKA_DICTIONARY.md](../docs/AZBUKA_DICTIONARY.md).
Новый поиск/чтение статьи требуют сети; наличие PWA не означает установки
полного словаря. Учебные карточки продолжают работать офлайн.

Учебные формулировки — первичный редакционный набор. Перед публичным релизом
значения имён, немецкую транслитерацию, правила цифири и контекстные примеры
должен проверить специалист по церковнославянскому языку. Системное озвучивание
отключено: оно не умеет корректно читать церковнославянский Unicode. Звук можно
вернуть только после подготовки собственного проверенного аудиопакета. Тексты и
графика стороннего приложения не использовались.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
cd azbuka-web
npm ci
npm run dev
```

Vite покажет локальный адрес, обычно `http://localhost:5173`.

## Проверка и production build

```bash
npm run check
```

Команда выполняет TypeScript-проверку, тесты и production build. Результат создаётся в `azbuka-web/dist`.

Общее обновление обеих версий выполняется из корня через `npm run build`.
Серверный `scripts/deploy-production.sh --with-azbuka` запускается в
`/var/www/vhosts/biblia-app.ru/httpdocs`, собирает обе версии и создаёт публичный
архив `dist/azbuka-release.tar.gz`. Отдельную Азбуку импортирует её собственный
пользователь Plesk в `/var/www/vhosts/bible-desktop.com/my_app/azbuka-web/dist`.
Скрипт не пишет в папку другого пользователя. Готовые команды — в корневом README.
Старый `my_app` не используется как источник Git или сборки.

Для production веб-сервер должен отдавать `index.html` для неизвестных маршрутов. Файл `public/.htaccess` добавляет нужное правило для Apache/Plesk; при использовании чистого nginx эквивалентом будет `try_files $uri $uri/ /index.html`.

## Данные пользователя

Аккаунт не нужен. Прогресс, словарные избранное и история хранятся в IndexedDB
текущего браузера. При обновлении схемы прежний прогресс сохраняется; сброс
учебного прогресса не удаляет словарные записи. Поисковый запрос отправляется
в публичный BibleDesktop API без cookies. Синхронизации между доменами нет.
