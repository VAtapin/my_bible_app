# «Азбука с цифирью» — Web App

Самостоятельный браузерный клиент тренажёра церковнославянской азбуки. Установка не требуется; после первого успешного открытия приложение работает offline как PWA.

## Что реализовано

- адаптивный app-like UI для телефона и компьютера;
- церковнославянский интерфейс по умолчанию с переключением на русский или
  немецкий в настройках;
- 37 учебных карточек букв и знаков;
- отдельный раздел церковнославянской цифири от 1 до 999 с пошаговым алгоритмом,
  правилами и таблицами разрядов;
- буквенные упражнения «знак → имя» и «имя → знак», не смешанные с цифирью;
- живые часы, минуты и секунды церковнославянской буквенной цифирью;
- локальные прогресс, точность, серия занятий и настройки в IndexedDB;
- прямые URL экранов и offline service worker;
- локально поставляемый шрифт Ponomar под SIL OFL 1.1.

Учебные формулировки — первичный редакционный набор. Перед публичным релизом
значения имён, немецкую транслитерацию, правила цифири и контекстные примеры
должен проверить специалист по церковнославянскому языку. Системное озвучивание
отключено: оно не умеет корректно читать церковнославянский Unicode. Звук можно
вернуть только после подготовки собственного проверенного аудиопакета. Тексты и
графика стороннего приложения не использовались.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
cd azbuka-web
npm ci
npm run dev
```

Vite покажет локальный адрес, обычно `http://localhost:5173`.

## Проверка и production build

```bash
npm run check
```

Команда выполняет TypeScript-проверку, тесты и production build. Результат создаётся в `azbuka-web/dist`.

Для production веб-сервер должен отдавать `index.html` для неизвестных маршрутов. Файл `public/.htaccess` добавляет нужное правило для Apache/Plesk; при использовании чистого nginx эквивалентом будет `try_files $uri $uri/ /index.html`.

## Данные пользователя

В этой версии аккаунт не нужен. Прогресс хранится только в IndexedDB текущего браузера. Синхронизация с API и перенос между устройствами запланированы отдельным этапом.
