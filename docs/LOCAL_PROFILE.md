# Локальный профиль и конструктор

## Назначение

Первый запуск создаёт локальную конфигурацию приложения без регистрации и
запроса системных разрешений. Пользователь выбирает быстрый пресет или собирает
разделы вручную, проверяет сводку и затем попадает на экран «Сегодня».

## Маршруты

| Маршрут | Назначение |
| --- | --- |
| `/` | первый экран; при наличии профиля автоматически открывает `/today` |
| `/setup/quick` | короткая настройка на основе пресета |
| `/setup/manual` | ручной выбор состава |
| `/setup/manual?edit=1` | повторное редактирование сохранённого профиля |
| `/today` | стартовый экран созданного приложения |
| `/reader` | рабочий сценарий чтения и локального сохранения главы |
| `/restore` | информационный экран до появления серверного восстановления |

## Модель и хранение

Версионированная модель `AppConfiguration` хранит:

- выбранные разделы;
- основной перевод Библии;
- состав ежедневной молитвы;
- детализацию календаря;
- выбор ежедневного напоминания и времени;
- режим первоначальной настройки и даты создания/обновления.

Репозиторий сохраняет JSON в localStorage под ключом
`bible-desktop:profile:v1`. При чтении данные проходят структурную проверку;
повреждённое или неизвестное значение не используется. Создание и нормализация
модели не зависят от Vue и покрыты модульными тестами.

LocalStorage выбран только для небольшой несекретной конфигурации PWA. Тексты,
пакеты контента, закладки и история чтения должны храниться в IndexedDB/SQLite.
Серверная синхронизация и восстановление будут добавлены отдельным контрактом с
основным API; секрет восстановления в localStorage хранить нельзя.

## Ограничения текущего этапа

- Библия ведёт в уже работающий экран чтения.
- Молитвы, календарь и изучение пока сохраняются в составе профиля, но их
  контентные экраны будут подключаться на следующих этапах.
- Выбор напоминания сохраняется, но запрос системного разрешения выполняется
  только в контексте нативной функции уведомлений.
