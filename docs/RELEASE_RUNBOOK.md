# Release runbook

## 1. Release candidate

1. Рабочее дерево чистое, ветка `main` синхронизирована с upstream.
2. Версии `package.json`, Android versionCode/versionName и iOS
   MARKETING_VERSION/CURRENT_PROJECT_VERSION согласованы.
3. `npm ci`, `npm run check`, `npm audit` проходят на Node.js 22.
4. `npm run cap:sync` завершён после production build.
5. Проверены миграции IndexedDB со старой схемы и сохранение пользовательских
   глав; SQLite будет добавлен только после выбора и device-проверки адаптера.
6. API profile feature-тесты проходят до публикации клиента.

## 2. Device matrix

Обязательный smoke test на реальных устройствах:

- iOS: минимальная поддерживаемая версия и актуальная версия;
- Android: минимальная поддерживаемая версия и актуальная версия;
- чистая установка, обновление поверх предыдущего RC, запуск offline;
- первый запуск, конструктор, глава, закладка, молитва, календарь;
- прерывание полной загрузки и повторный запуск;
- запрет/разрешение уведомлений, переход по уведомлению;
- смена часового пояса и даты;
- персональная ссылка, код восстановления, экспорт и удаление;
- крупный шрифт, VoiceOver/TalkBack и ширина 320 px.

## 3. Закрытые каналы

- iOS: загрузить подписанную сборку в App Store Connect, дождаться processing,
  заполнить Test Information и включить TestFlight-группу.
- Android: загрузить подписанный AAB во внутренний track, затем в закрытый track;
  заполнить Data safety, content rating и доступ тестеров.
- PWA: развернуть тот же commit только после успешных автоматических проверок;
  проверить manifest, service worker, SPA fallback и `/privacy`.

## 4. Go/no-go

No-go при потере локальных данных, невозможности восстановить профиль,
неработающем offline после перезапуска, падении запуска, неправильном переходе
из уведомления или утечке секрета/токена в URL query, журнал или диагностику.

## 5. Наблюдение

Диагностическая сводка хранится локально и экспортируется самим пилотным
пользователем. Она содержит только счётчики заранее заданных событий и категорий
ошибок. Сообщения исключений, stack trace, тексты, запросы, ссылки и токены не
записываются. Автоматическую отправку не включать без отдельного согласия,
privacy review и серверной политики retention.
