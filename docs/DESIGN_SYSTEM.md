# Дизайн-система Bible Desktop

## Источник фирменного стиля

Единый источник визуальных материалов находится в соседнем проекте:

```text
D:\Projekte\BibleDesktop\UI
```

Основной референс — `ChatGPT Image 24. Juni 2026, 21_29_56.png`. Иконки,
логотипы и изображения приложения берутся из этой папки. Новые пиктограммы не
должны смешиваться с другим графическим стилем без отдельного решения по всему
семейству иконок.

## Цвета

| Роль | Цвет | Применение |
| --- | --- | --- |
| Основной синий | `#4A6B8A` | главные действия, активная навигация, фирменные поверхности |
| Светлый синий | `#7DA1C2` | вторичные акценты, состояния, фокус и номера стихов |
| Кремовый | `#EDE6D6` | мягкие декоративные поверхности |
| Основной фон | `#F7F5F1` | фон приложения и splash screen |
| Золотой | `#B99A5A` | редкие тонкие акценты, связанные с церковной символикой |

Золотой не используется как основной фон, цвет большой кнопки или доминирующий
элемент интерфейса. Текст и рабочие контролы строятся прежде всего на синей
части палитры.

## Принципы интерфейса

- Интерфейс проектируется как мобильное приложение, а не как уменьшенная
  страница сайта: полноэкранная оболочка, фиксированная нижняя навигация,
  прокручиваемая центральная область и поддержка safe area.
- Основной сценарий должен помещаться в один понятный экран без маркетинговой
  шапки, вкладок браузерного вида и широких desktop-панелей.
- Интерактивная область элемента должна быть не меньше 44 пикселей.
- Системный sans-serif используется для элементов управления; Georgia — для
  заголовков и чтения библейского текста.
- Карточки остаются светлыми, с тонкой границей и умеренной тенью. Скругления и
  декоративные эффекты не должны конкурировать с содержанием.
- Состояния online/offline видимы, но не отвлекают от чтения.
