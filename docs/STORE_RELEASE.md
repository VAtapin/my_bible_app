# Материалы для App Store и Google Play

Документ фиксирует тексты и disclosures для первой закрытой сборки. Перед
отправкой их нужно сверить с фактическим бинарником: ответы магазинов описывают
именно поведение загружаемой версии, включая все сторонние SDK.

## Полное описание

Bible Desktop помогает собрать личное приложение для ежедневного чтения.
Выберите нужные разделы и получите спокойный мобильный интерфейс без лишнего:

- Библия с выбором перевода, закладками и продолжением с последнего места;
- молитвослов с сохранением прочитанного для работы без сети;
- церковный календарь, пост и чтения дня;
- управляемые локальные напоминания по выбранным категориям;
- загрузка перевода и календарного горизонта для офлайн-доступа;
- защищённая персональная ссылка и код восстановления конфигурации.

Аккаунт не обязателен. Содержание чтения, молитв и поисковых запросов не
собирается в аналитику. Серверный профиль создаётся только по явному действию,
его можно экспортировать и удалить в приложении.

## Сценарий скриншотов

Снимать только реальный release build, без рамок чужих устройств и без
функций, которых нет в бинарнике.

1. Первый экран: «Ваше приложение. Ваш ритм.»
2. Конструктор с выбранными разделами.
3. Экран «Сегодня» с карточками Библии, молитв и календаря.
4. Чтение главы и закладка.
5. Офлайн-хранилище и загруженный перевод.
6. Расписание уведомлений.
7. Профиль, экспорт и восстановление без показа реального секрета.

Для App Store требуется от одного до десяти скриншотов. Сначала подготовить
портретный набор для максимального поддерживаемого iPhone; App Store Connect
может масштабировать его для меньших размеров. Для Google Play подготовить
тот же правдивый набор и отдельную feature graphic после проверки текущих
размеров в Play Console.

## Privacy disclosures для текущей сборки

Фактическое поведение версии 0.1.0:

- нет рекламы и рекламных SDK;
- нет стороннего аналитического SDK;
- агрегированные продуктовые счётчики и категории ошибок остаются на устройстве;
- локальные тексты, закладки и место чтения не отправляются в профиль;
- при добровольном создании профиля сервер получает конфигурацию, случайный ID,
  ревизию и служебные даты; профиль можно экспортировать и удалить;
- секрет передаётся только по HTTPS-заголовку, хранится сервером как SHA-256 и
  локально только в пределах сессии;
- APNs/FCM ещё не подключены, поэтому текущий бинарник не отправляет push-токен;
- сервер может получать IP-адрес и стандартные технические журналы запросов для
  безопасности и устранения сбоев.

Предварительное заполнение форм:

- App Store: не выбирать tracking; проверить необходимость категории User ID
  для случайного ID профиля и Other Data для конфигурации, назначение — App
  Functionality, не реклама. Ответ должен включать практики серверных журналов.
- Google Play Data safety: данные не продаются и не передаются рекламным сетям;
  профиль передаётся по HTTPS, собирается опционально для функциональности,
  доступно удаление. Локальные данные не считаются собранными, пока не уходят с
  устройства.

Окончательные ответы заполняет владелец аккаунта магазина после просмотра
собранного AAB/IPA и списка SDK.

## App Review notes

Приложение работает без регистрации. Для проверки:

1. выбрать «Быстрая настройка»;
2. выбрать готовый набор и завершить конструктор;
3. открыть Библию, молитвы и календарь с экрана «Сегодня»;
4. открыть «Профиль и перенос», создать тестовый профиль, проверить экспорт и
   удалить профиль;
5. уведомления запрашиваются только после включения категории пользователем.

Особые credentials не требуются. Сетевой контент приходит с публичного API,
адрес которого задаётся в `config/api-base-url.txt`. Персональная ссылка
содержит секрет после `#`;
fragment не отправляется веб-серверу.

## Внешние шаги

- принять актуальные соглашения Apple Developer и Google Play;
- создать записи приложения в обоих кабинетах;
- проверить content rating, DSA/trader status, экспортное соответствие и страны;
- собрать подписанные IPA/AAB;
- заполнить privacy/Data safety по фактическому бинарнику;
- загрузить скриншоты и карточки;
- отправить сначала в TestFlight и закрытый track Google Play.
