# ЕДИНСТВЕННЫЙ API — BIBLEDESKTOP

ВСЕ ДАННЫЕ ПРИЛОЖЕНИЯ, ВКЛЮЧАЯ КАЛЕНДАРЬ, БЕРУТСЯ ИЗ API BIBLEDESKTOP.

- Проект API: `D:\Projekte\BibleDesktop`.
- Единственный адрес: `config/api-base-url.txt`, переопределение `VITE_API_BASE_URL`.
- Календари дня, недели и месяца, иконы, посты, Типикон и служебные тексты
  используют этот же API; отдельный календарный источник запрещён.
- Недостающие функции добавляются в проекте BibleDesktop по согласованию
  с его чатом и потребителями. Клиент не создаёт собственный календарный движок.
- Изменения API здесь не выполняются. Старые офлайн-данные другого источника
  нельзя выдавать за данные BibleDesktop; пользовательское хранилище не удалять.
