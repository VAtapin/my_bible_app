# PROJECT_STATUS

## Реализовано / текущее состояние

- Веб: Vue 3/TypeScript PWA, интерфейс RU/DE/UK/EN, персональная настройка,
  три оформления, Библия, молитвы, календарь, локальные заметки/закладки,
  уведомления, профиль и встроенная/standalone «Азбука» (37 букв, цифирь,
  упражнения/прогресс). Публичное название — Bible App; технические ключи,
  идентификаторы и API BibleDesktop не переименованы.
- Android: самостоятельный Jetpack Compose/KMP UI без WebView, пакет
  com.bibledesktop.myapp, debug отдельно (.debug). Храм, адаптивные раскладки,
  быстрый запуск, ручная настройка «Сохранить», язык интерфейса в настройках.
  Удобный выбор книги/главы прямо из читалки, точные ссылки/подсветка стиха,
  два режима сравнения, заметки/закладки/share, реальные cross-references/Strong,
  четыре локальных напоминания с явным изменением времени и About.
  Inter/Noto Serif/Ponomar/Monomakh встроены с OFL.
- 09.10.2026: **веб — «Включённые / Каталог», Android — «Загруженные / Каталог»**,
  поиск и фильтры группа → язык. Веб включает/отключает перевод без установки;
  Синодальный включён по умолчанию. Используется
  /translations?catalog=available (не короткий default и не непубличный all).
  Каталог растёт во время импорта, числа не зашиты. Группы — точные Glottolog
  соответствия (CC BY 4.0); неизвестные языки доступны в «Другие»/поиске.
  Фильтры четырёх языков удалены только из выбора Библий.
- Над списком выбранных переводов постоянно доступен прямой вход в каталог:
  веб «Включить другие переводы», Android «Скачать другие переводы».
  Кнопка видна без прокрутки, не зависит от пустого списка и сбрасывает фильтры
  при открытии каталога; подписи переведены на RU/DE/UK/EN.
- **Веб читает/ищет через API**, сравнение загружает нужную главу без целого пакета.
  Ранее сохранённые тексты оставлены; fallback только на сеть/таймаут, не HTTP-ошибки.
  Пустой экран не дублирует сообщение и имеет явную ссылку сразу в каталог.
- **Android читает Библию локально**. Синодальный входит в APK как gzip-снимок
  публичного API (6.14 MB, 66 книг, 1189 глав; Даниил 13/14 отсутствуют в источнике).
  На первом запуске копируется без сети с финальным маркером после записи всех глав;
  повторный запуск сохраняет имеющийся текст. Другие переводы устанавливаются.
  Незагруженная редакция предлагает каталог, без подмены. Изучение/словари используют
  API, не входят в полный пакет Библии. Старые данные сохранены, миграций нет.
  Пустые главы и отдельные стихи источника перечислены явно; доступный пакет
  можно читать, но он не называется полным текстом.
- Установка: все доступные главы по реальному каталогу, проверка идентичности,
