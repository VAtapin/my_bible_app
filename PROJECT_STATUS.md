# PROJECT_STATUS

## Реализовано / текущее состояние

- Веб: Vue 3/TypeScript PWA, интерфейс RU/DE/UK/EN, персональная настройка,
  три оформления, Библия, молитвы, календарь, локальные заметки/закладки,
  уведомления, профиль и встроенная/standalone «Азбука» (37 букв, цифирь,
  упражнения/прогресс). Публичное название — Bible App; технические ключи,
  идентификаторы и API BibleDesktop не переименованы.
- Android: самостоятельный Jetpack Compose/KMP UI без WebView, пакет
  com.bibledesktop.myapp, debug отдельно (.debug). Храм, адаптивные раскладки,
  быстрый запуск, ручная настройка «Сохранить», язык интерфейса в настройках.
  Удобный выбор книги/главы прямо из читалки, точные ссылки/подсветка стиха,
  два режима сравнения, заметки/закладки/share, реальные cross-references/Strong,
  четыре локальных напоминания с явным изменением времени и About.
  Inter/Noto Serif/Ponomar/Monomakh встроены с OFL.
- 09.10.2026: **веб и Android — «Библии»: «Загруженные» и полный публичный
  «Каталог», Install/Read, поиск и фильтры группа → язык**. Используется
  /translations?catalog=available (не короткий default и не непубличный all).
  Каталог растёт во время импорта, числа не зашиты. Группы — точные Glottolog
  соответствия (CC BY 4.0); неизвестные языки доступны в «Другие»/поиске.
  Фильтры четырёх языков удалены только из выбора Библий.
- **Библия всегда читается локально**: чтение, сравнение и поиск используют
  установленные редакции. Незагруженный перевод/глава предлагает установку,
  не подменяется другим переводом. Изучение/словари всё ещё могут использовать
  API, не входят в полный пакет Библии. Старые данные сохранены, миграций нет.
  Пустые главы и отдельные стихи источника перечислены явно; доступный пакет
  можно читать, но он не называется полным текстом.
- Установка: все доступные главы по реальному каталогу, проверка идентичности,
  committed progress и отмена/продолжение с аудитом сохранённых файлов.
  Android: отдельные WorkManager jobs для редакций, последовательная загрузка,
  Wi-Fi-only, шестиминутные порции; общий искусственный предел 256 MiB снят,
  проверяется свободное место, JSON до 5 MiB. Веб: прежняя IndexedDB, ожидание
  commit транзакций, запрос persistent storage; держать страницу открытой при
  загрузке, после закрытия продолжить сохранённые главы. Очистка данных браузера
  удаляет локальные тексты; предоставление постоянного storage зависит от браузера.
- Календарь обеих версий — BibleDesktop: месяц/неделя/день, старый стиль, пост,

## Известные ограничения / далее

- Источник не исправляем: KJV 1Samuel 2–8 и RU Daniel 13/14 были пустыми;
  новые модули могут иметь объединённые/пустые стихи. Не выдумывать текст.
  У API нет языковых семей; новые неизвестные коды консервативно попадают в «Другие».
- Неполная локализация календарного контента (icons/food/typikon могут быть RU);
  владелец запретил создавать отсутствующие переводы. EN календарь использует RU,
  standalone Азбука RU/DE/CU. Молитвы cu: один текст, cu-civil: нет;
  русские тексты не подменяют эти редакции.
- Синхронизация/перенос профиля исключены владельцем. Данные браузера локальны
  для origin; автоматического обмена доменами нет. Android Азбука/OCR/360°,
  аудио, APNs/FCM, полные молитвенные пакеты/Часослов пока не реализованы.
- App Links требует production assetlinks.json с Play App Signing сертификатом;
  последняя проверка возвращала HTML. Manifest готов, debug в association не включать.
- До Play: физический ARM64/авиарежим/перезагрузка/Play splits, права на тексты и
  изображения, анкеты Data Safety/IARC/аудитории/страны/цена и review политики.
  RELRO end graphics-path .so не 16-KB aligned: warning сохранён, строгий аудит
  отклоняет; прошлый x86_64 16-KB runtime проходил, ARM64 не проверен.
  Владелец ещё должен резервировать ключ независимо от Windows DPAPI.
- iOS build/проверки требуют macOS/Xcode. Safari/iPad и учебный корпус требуют проверки.
