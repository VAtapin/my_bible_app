# PROJECT_STATUS

## Реализовано

- Vue 3/TypeScript PWA: персональная настройка, Библия, молитвы, календарь,
  локальное хранилище, уведомления и профиль; три оформления.
- Интерфейс RU/DE/UK/EN. На старте сразу видны родные названия языков.
  /ru, /de, /uk, /en явно задают язык; адрес без языка использует сохранённый
  выбор, затем язык домена/браузера. Старые профили совместимы.
  UK/EN предлагают реальные BQ_UKRAINE / BQ_ENGLISH_KJV_1769.
- Старт без профиля: оригинальный храм, название/описание, три действия,
  цитата, месяц и краткая сводка выбранного дня, конфиденциальность.
  Hero на всю ширину телефона/портретного планшета и на левую половину
  альбомного планшета. Нет прежних пустых вертикальных блоков.
  Дублирующие панели скрыты только здесь; профиль открывает «Сегодня».
- «Быстро настроить» сразу создаёт полный профиль и открывает «Сегодня»:
  все четыре раздела, все шесть молитвенных категорий, Азбука/часы/прогресс,
  все события календаря. Язык выбирается на старте, перевод Библии соответствует
  ему; RU/CU/CU-civil корпуса не переименовываются. Дополнительных шагов,
  массового скачивания и запросов разрешений нет; уведомления включаются отдельно.
  Повторный quick URL не перезаписывает существующий профиль. Ручной мастер сохранён.
- public/brand/welcome-church.png (1122 × 1402) сохранён без ретуши, Downloads
  не изменён. Кадрирование — CSS. PNG предкэшируется с SHA-256 revision.
- Build создаёт статические языковые страницы с OG/Twitter метаданными
  без необходимости JavaScript и четырьмя JPEG 1200 × 630.
  Композиция — tools/social-preview.html, строки — config/social-pages.json.
- Оболочка до 1120 px, safe area, постоянные панели и контейнерные раскладки.
  Wide-reader использует ширину app с обычными отступами, шрифт не меняется.
  Главная: квадратный месяц и колонки одной высоты, стих 18/20 px; часы
  центрированы, цифирь 39 px, сверху «Часы», снизу время с секундами.
- «Сегодня»: единая дата со старым стилем, настоящий случайный стих,
  ранжированная икона/памяти/пост/чтения, продолжение чтения. «Азбука» всегда
  показывает часы, включая старые профили с showClock:false.
- Окно иконы: отдельный класс большого изображения не наследует размеры
  миниатюр карточки; окно до 960 px / 94vw, изображение до 68dvh / 820 px,
  object-fit:contain, прокрутка длинного описания. Маленькие offline-превью
  и полные изображения API не менялись. Проверочный стенд — tools/icon-viewer-check.html.
  Галерея перелистывается горизонтальным свайпом по изображению (Pointer Events,
  capture указателя), включая переход по кругу; стрелки сохранены. Вертикальное
  движение, короткое касание, отменённый жест и мультитач не перелистывают.
  touch-action:pan-y pinch-zoom сохраняет прокрутку и масштабирование браузером.
- Календарь использует ТОЛЬКО API BIBLEDESKTOP: /calendar/month (один полный
  месяц), /calendar/day, /calendar/service. Отдельный клиент и адрес календарного
  API удалены. День/неделя/месяц и полный день используют тот же источник;
  относительные пути знаков разрешаются против BibleDesktop, не frontend.
  Старые поля совместимы, указания не повторяются в списке памятей.
  Иконы сохраняют порядок сервера, без сравнения локализованных названий.
- «Офлайн-горизонт»: 30 полных дней BibleDesktop, нужные месяцы, служебные тексты
  и главное превью каждого образа (до 320 px / 80 KiB), не полные галереи.
  Скачивание использует фактический imagePreviewUrl API; Blob хранится под
  исходным image_url для совместимого отображения сохранённого дня.
  Все знаки месячной сетки тоже сохраняются, включая дни за пределами горизонта.
  Оригинальные пять SVG Типикона и восемь PNG поста/поминания из BibleDesktop
  включены в PWA: SVG встроены в JS, PNG предкэшируются; static CORS API для
  этих файлов не нужен. SHA-256 копий совпадает с оригиналами f3903f00.
  Неизвестные ресурсы не подменяются. Счётчик растёт после commit
  транзакции; видны диапазон, завершение, недостающие ресурсы, отмена/ошибка.
  Готовые дни сохраняются при сбое. Blob читаются через OfflineImage.
  Используется прежний IndexedDB state без миграции/изменения личных данных.
  Запросы пакета идут последовательно с интервалом не менее 2100 ms;
  429 повторяется один раз после Retry-After, ожидание отменяемое.
  Новый namespace месяца/горизонта и source-check дня не принимают сохранения
  удалённого источника за данные BibleDesktop; старые записи не удаляются.
- Молитвы: безопасные структурированные блоки, точные cu/cu-civil редакции;
  Ponomar для традиционного Unicode и заголовков, Monomakh Unicode для
  гражданской редакции. Шрифты/OFL локальны. Источник/ссылка под текстом убраны,
  метаданные API сохранены. BibleDesktop исправляет повтор body из секций
  и подтверждённую лишнюю карточку «Отче наш» без удаления записей.
- Чтение: точные ссылки/выделение стиха, закладка, размер, поделиться, поиск
  API, заметка. Правый клик/долгое нажатие/«Ещё» открывают единое меню;
  подвал «Закладки»/«Заметки» — личные списки. Старые записи читаются офлайн
  и редактируются, новая база не создавалась.
- «Азбука»: 37 букв, примеры, цифирь 1–999, упражнения/прогресс. Встроенная
  /education/azbuka и standalone используют azbuka-web/src.
  Карточка буквы компактнее: min-height 160 вместо 195 px; цитата CU —
  28 px на узком экране, адаптивно до 40 px на широком. Ponomar, содержание
  и размеры обычного перевода не изменены. Оба варианта используют одни стили.
  Нативный KMP-каркас Android/iOS сохранён; эта задача касается web.

## Важные решения и deployment

- Основной API: D:\Projekte\BibleDesktop; config/api-base-url.txt / VITE_API_BASE_URL.
  Сервер: /var/www/vhosts/bible-desktop.com/httpdocs, Plesk PHP 8.4.
  Маленькие изображения — существующий image endpoint с ?preview=1, нужен GD/WebP.
- ЕДИНСТВЕННЫЙ API — BIBLEDESKTOP, ВКЛЮЧАЯ КАЛЕНДАРЬ (API_SOURCE.md).
  Недостающие функции дополняет чат BibleDesktop; согласование с чатом Kalendar
  выполнено. API commit f3903f00 Expose local calendar API pushed в origin/main.
  Приложение не правит общий API и не рассчитывает праздники/посты/ранги.
  Только сеть/таймаут разрешают fallback, не 401/403/429/invalid data/invalid JSON.
- PWA: /var/www/vhosts/biblia-app.ru/httpdocs, Document Root dist, Node.js 22.
  npm run build собирает main и standalone, npm run check — типы/тесты/build.
- RU/DE канонические домены biblia-app.ru / bible-app.de сохранены;
  biblia-app.de — DE, bible-app.online — браузер. Для UK/EN домены не придуманы.
- Standalone: /var/www/vhosts/bible-desktop.com/my_app/azbuka-web/dist.
  Домены имеют разных пользователей Plesk; общий скрипт записи в обе папки
  не применять. Старый родительский my_app не используется для Git/build.
  Стили «Азбуки» изменены: требуется обновить обе сборки; перенос standalone
  публичным архивом описан в README (разные пользователи Plesk).
  Commit/push не является deployment.
