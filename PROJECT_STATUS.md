# PROJECT_STATUS

## Реализовано

- PWA на Vue 3/TypeScript остаётся самостоятельным браузерным клиентом для
  `https://my.bible-desktop.com`.
- В `mobile/` развивается отдельное Kotlin Multiplatform-приложение без WebView:
  Jetpack Compose для Android, SwiftUI для iOS, общий Ktor API-клиент и модели.
- Реализован фирменный RU/DE onboarding по согласованному UI: быстрый и ручной
  режимы, три шага, выбор разделов и независимый множественный выбор переводов.
- Выбор интерфейса, разделов и переводов сохраняется локально; после холодного
  запуска открывается собранное пользователем приложение.
- Реализовано нативное чтение Библии: выбранные переводы, каталог книг, главы,
  текст production API, изменение размера шрифта, переход по главам, закладки и
  системная отправка отдельного стиха.
- Реализован нативный молитвослов: каталог по языку, чтение молитвы, размер
  текста и системная отправка.
- Реализован нативный церковный календарь: переход по дням, новый/старый стиль,
  пост, памяти и чтения дня.
- Те же маршруты и пользовательские сценарии подготовлены в SwiftUI; общий API
  предоставляет Swift-friendly loaders для переводов, Библии, молитв и календаря.
- Общие контракты production API покрыты unit-тестами для переводов, книг, главы,
  языковой фильтрации молитв и календаря.
- Bundle/application ID обеих платформ — `com.bibledesktop.myapp`.

## Текущее состояние

Android debug APK собирается, установлен на эмулятор API 37 и проверен на живом
production API. Полностью пройдены быстрый и ручной onboarding, холодный запуск,
чтение немецкой главы, сохранение закладки, русский молитвослов и календарь.

iOS-реализация поддерживает те же основные сценарии на уровне исходников, но её
нужно собрать и визуально проверить на macOS/Xcode. Store-релиз пока не готов:
не завершены подпись, store metadata, offline-кэш, уведомления и release QA.

Старые `android/` и `ios/` Capacitor-проекты сохранены только как исходная
реализация; целевой мобильный код находится в `mobile/`.

## Важные решения

- PWA, Android и iOS — три клиента одного Bible Desktop API.
- Android UI пишется на Jetpack Compose, iOS UI — на SwiftUI; KMP разделяет API,
  модели и тестируемую прикладную логику, но не UI.
- Основа UI — вариант №1 из `UI/`; из варианта №3 перенесены три шага, крупные
  зоны нажатия, переключатели, компактный выбор переводов и панель чтения.
- Язык интерфейса не ограничивает языки Библии. Приоритетным сначала становится
  перевод языка интерфейса, но пользователь может мгновенно выбрать любой из
  добавленных переводов.
- Приложение не показывает русский молитвенный текст как немецкий: ответы API
  дополнительно фильтруются по фактическому `language_code`.
- Идентификатор — `com.bibledesktop.myapp`; версия пока `0.1.0` (build 1).
- Android: min SDK 26, compile/target SDK 37, JDK 25. iOS: minimum 16.0.
- Секреты подписи Android/iOS не хранятся в Git.

## Известные проблемы

- Production endpoint `/api/prayers?language=de` сейчас возвращает 23 русских
  записи с `language_code=ru`; поэтому немецкий молитвослов корректно показывает
  пустое состояние. Немецкий корпус требуется импортировать в основной API.
- iOS build, Swift/Kotlin interop и визуальная проверка требуют macOS/Xcode.
- Общий offline-кэш для глав, молитв и календаря ещё не реализован.
- APNs/FCM, локальные расписания уведомлений, deep links и store-подпись ещё не
  подключены.
- Закладки сохраняются и отображаются в текущей главе, но отдельный общий каталог
  закладок ещё не добавлен.
- Экран «Сегодня» использует локализованную статическую цитату, а не endpoint
  чтений дня.
